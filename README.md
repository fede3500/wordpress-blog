# 📝 WordPress Blog

## 📖 Overview

This project is a blog built with WordPress, designed to provide a modern, responsive, and user-friendly platform for publishing and managing digital content.

The main objective of this project is to demonstrate practical skills in web development, WordPress administration, CMS configuration, and website deployment.

## 🚀 Features

- Responsive web design.
- Content management with WordPress CMS.
- Blog posts, categories, and tags.
- Media and image management.
- User and role management.
- Customizable themes and plugins.
- SEO-friendly structure.
- WordPress administration dashboard.

## 🛠️ Technologies

- WordPress
- PHP
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## ⚙️ Installation

### Prerequisites

- PHP
- MySQL or MariaDB
- Apache or Nginx
- WordPress

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/fede3500/wordpress-blog.git
   ```

2. Configure your local web server.
3. Create a MySQL database.
4. Configure the `wp-config.php` file with your database credentials.
5. Import the database backup, if available.
6. Open the website in your browser and complete the WordPress setup.

## 🔒 Security

Sensitive information, database credentials, and environment-specific
configuration files should not be included in the repository.
